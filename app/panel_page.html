🎚 预设（只影响尺度与口吻）

三种预设共用同一套硬红线，切换立即生效，不用重启。

⛔ 硬红线（不可覆盖）

① 不协助破解、去授权、绕过任何软件的付费与授权机制：卡密、激活码、注册机、试用期绕过、license check patch、伪造激活。
② 不编写、不改写、不分发危害型恶意程序：病毒、蠕虫、勒索软件、远控木马、窃密工具、面向真实破坏的载荷。
其余话题按上面的尺度正常回答，不再额外设限。
红线段写死在 app/jailbreak.py 的 _REDLINES 常量里， 预设改不动、对话也取消不掉。要改只能改代码。

🔍 自检（改了不生效时点这里）

检查三件事：条款能不能拼出来、当前状态是否真的生效、内核进程里加载的是不是新代码。

⚡ 第一次使用（约 10–20 分钟，以后每次 1 分钟）

    
按顺序做完四步就能聊；卡住看本页底部排障表

    
1
配模型 —— 🧠 模型配置 → 点提供商胶囊 → 填 API Key → 🔌 测试连通出现 ✅ → 💾 保存并重启机器人（只聊天用文本模型即可）

    
2
连 QQ —— 🚀 运行控制 → ▶ 启动内核 → ▶ 启动协议端 → 用小号扫二维码（约 2 分钟有效，过期点 🔄 刷新二维码）→ 手机点授权

    
3
认领管理员 —— 用主号私聊机器人：我是主人 认领码（认领码见下方认领码提示；10 分钟有效）→ 收到「✅ 你已成为管理员」。不认领：换人设/看状态/抖音都用不了

    
4
开聊 —— 主号加小号好友，私聊直接发消息；群里 @机器人 或 /命令；发 帮助 看完整菜单

    
⚠ 只用小号（协议端有风控风险）；数据都在本机；面板不要暴露到公网。

    
🔀 用 WorkBuddy 反代：先去「🔀 反代」启动并接入，再在反代页选精确模型 ID（如 deepseek-v4.1-flash）；不要在「🧠 模型配置」里直连切换反代模型。

🧩 插件

    
🧩 插件页：上半是内置开关（即点即生效），下半是市场（点 ⬇ 自动装依赖）

    
· 联网 / 语音 / 表情包：默认开，零配置

      · 抖音真机：市场安装 → 手机开 USB 调试连电脑 → QQ 发「连接手机」

      · 定时任务：内置默认开，在「⏰ 定时任务」页配置（不是市场插件）

      · 反代：独立页，不是插件；按「🔀 反代」页说明接入 WorkBuddy

      · 第三方插件装完内核自动重启（QQ 不受影响）；内核没开则提示"下次启动生效"

      · ⚠ 对话类第三方插件会和内置聊天抢消息，二选一

  


  

    
🖼 看图（可选，需多模态模型）

    
默认关闭。开启三步：① 换多模态模型（qwen-vl / glm-4v / gpt-4o / gemini 等）② 记事本改 .env：VISION_ENABLED=true ③ 重启内核

    
然后私聊/群@ 直接发图就能聊；图片在本机下载校验后发给模型。文本模型发图会提示"不支持看图"。

  


  

    
🎬 抖音真机（可选，管理员，需多模态模型）

    
AI 看手机屏幕两帧画面决定 多看/点赞/关注/划走——真滑动、真声音（手机播放）。AI 只看截图帧，没有声音，问内容措辞以画面为准

    
① 市场安装「抖音真机」② 手机开 USB 调试连电脑、装好抖音、保持解锁亮屏 ③ QQ 发「连接手机」诊断 →「刷抖音 分钟」

    ⚠ 单次 ≤60 分钟、每日 ≤120 分钟；违反平台协议有风控风险，仅限小号自用；"AI 连续失败"= 模型看不了图

  


  

    
🔀 反代（WorkBuddy 网关）

    
每个用户在自己电脑上跑自己的 WorkBuddy-Hub，登录自己的 WorkBuddy 账号；不经过作者或他人的服务器。

    

      首次：点「🌐 登录 WorkBuddy」；如果没装 WorkBuddy-Hub，面板会自动从官方 GitHub Release 下载到 data/workbuddy-hub（约 10 MB，SHA256 校验）并启动。

      登录：打开看板 →「+ 添加账号 (OAuth)」→ 浏览器登录（国际版/国内版），账号自动入库；检测到账号就绪会自动接入，也可回来点「🔎 检测并接入」。看板密码默认 admin，首次登录后建议改掉。

      接入：健康检查通过后自动拉模型、写模型源、重启内核；已有安装时不用填路径/端口。

      换模型：在「模型」下拉里选精确 ID（如 deepseek-v4.1-flash），或手动输入后点「应用模型」/回车；换模型会重启内核。

      切回：点「⏹ 停止并切回直连」，恢复启动前的直连模型并重启内核。
    

    
⚠ 模型名必须用 /v1/models 的精确 ID：是 deepseek-v4.1-flash，不是 deepseek4.1flash。

      ⚠ 反代激活时，「🧠 模型配置」里的直连保存只存档案、不激活；要换反代模型必须在「🔀 反代」页操作。

      ⚠ 已有 WorkBuddy-Hub 放在别的盘：在「高级」里填含 wb_proxy.py 的目录；离线安装可把发布包放到 data/workbuddy-hub.zip。

      ⚠ 显示“外部启动”时面板停不掉它；请去 WorkBuddy 看板/任务管理器停止。启动失败看 data/proxy.log。

  


  

    
⏰ 定时任务（管理员）

    
面板配 cron + 内容，到点自动往指定群/好友发消息；QQ 里也能配。

    

      面板：⏰ 定时任务 → 填名称 / cron / 内容 / 目标（群号，或 friend:QQ号）→ 保存；同名保存=更新，列表里可开关/编辑/删除。

      先测：QQ 发 定时任务 立即 名字，确认能发出去再等 cron。

      cron：五段「分 时 日 月 周」，例：0 9 * * 1-5=工作日 9:00；*/30 * * * *=每 30 分钟；30 8 * * *=每天 8:30；周字段 0=周日。

      QQ：定时任务 添加 名字 | cron | 内容 | 群号（好友用 friend:QQ）· 定时任务 列表/删除/开启/关闭/立即 名字
    

    
⚠ 群聊命令需 @ 或 / 前缀；单条内容 ≤500 字、最多 50 个任务。

      ⚠ 依赖内核运行：内核/插件关闭时不发，面板会显示调度器状态；停机期间错过的任务不会补发。

      ⚠ 发送失败会记录在列表，不保证同一分钟重试；先「立即」测好群号/好友号。

  


  

    
🩺 不回话？三步排查

    
1
Key 灯没绿 → 模型配置测试连通：401=Key 错 · 402=余额不足 · 404=模型名错

    
2
QQ 灯没绿 → 重启协议端刷新二维码重扫；互踢=两个程序登同一号

    
3
都绿不回 → 看 📜 运行日志末尾；"发送被QQ拦截"=临时风控，等几分钟自动恢复

    
反代/定时任务专项：换模型后仍用旧模型 → 反代页重新选精确 ID（如 deepseek-v4.1-flash）；定时任务不发 → 先 QQ 发「定时任务 立即 名字」测发送，再看调度器状态/群号/风控。
